One fortune cookie line for a crypto trader who just got liquidated: the
classic "tall, dark stranger" fortune, except the stranger turning up at the
door is the trader's own liquidation price — and it has been waiting there
patiently all along.

## Run it

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt` (97 characters, 16 words, UTF-8).
